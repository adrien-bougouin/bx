# AI Contribution Guidelines
AI-assisted contributions are welcome in this project, under the same terms as any other contribution.

## Rules
1. Adhere to the vision: read and follow [VISION.md](VISION.md).
   - If a request conflicts with it, stop and raise the conflict instead of working around it.
2. Do not modify [VISION.md](VISION.md).
3. Adhere to the contribution rules: read and follow [CONTRIBUTING.md](CONTRIBUTING.md).
4. Do not modify [CONTRIBUTING.md](CONTRIBUTING.md).

## Changelog
Add user-facing changes to the `[Unreleased]` section of [CHANGELOG.md](CHANGELOG.md).

## Verification
- Verify commands, options, and behavior against the source, tests, README, and manual page; do not invent them.
- Run the checks required by [CONTRIBUTING.md](CONTRIBUTING.md).
- Review the final diff before finishing.
- Report which checks were run and their outcome.
  - If a check cannot run, say so rather than claiming success.
